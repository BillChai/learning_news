   一句話：PG19 把 autovacuum 排程從「依系統目錄順序」改成依交易 ID/multixact 老化、dead tuple 數、寫入量、統計新鮮度五個加權分數排序，並開放 6 個新參數調權重，還新增 `pg_stat_autovacuum_scores` view 讓行為變得可觀測、可除錯，而不必再猜原始碼。維運 Postgres 的人值得先看懂新機制。

4. **[工程知識/AI] Microsoft 三層式 LLM Routing 架構：AKS 上的 Agent 省錢術**
   一句話：拆解一套給 agentic workload 用的三層架構——RouteLLM 用矩陣分解模型做語意路由（判斷便宜模型能不能打平強模型品質）、agentgateway 做認證/限流/成本追蹤、Kubernetes Gateway API Inference Extension 依 vLLM 的 KV-cache 佔用與佇列深度做 GPU-aware 排程；實測只把約 26% 呼叫導去強模型，就拿到 GPT-4 約 95% 的 MT-Bench 品質，省下最多 85% 成本。做 LLM 應用後端的具體參考架構。
   來源：InfoQ（Claudio Masolo）— https://www.infoq.com/news/2026/07/microsoft-agents-aks-routing/ ｜發布：2026-07-29｜配額類別：工程知識/教學｜來源類型：優先來源清單（InfoQ）
